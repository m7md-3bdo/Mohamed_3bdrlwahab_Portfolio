# Mohamed Abdelwahab — Personal Portfolio

A personal portfolio website built with HTML and CSS to showcase my background, skills, and front-end projects.

## 🌐 Live Demo

[View My Portfolio](https://m7md-3bdo.github.io/Mohamed_3bdrlwahab_Portfolio/)

## ✨ Features

- Personal introduction and about section
- Skills and services showcase
- Projects portfolio
- Smooth hover effects and transitions
- Responsive layout using CSS media queries
- Contact section with social links

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## 🎯 Purpose

This project was built as part of my front-end development learning journey to practice website layout, styling, and responsive design.
